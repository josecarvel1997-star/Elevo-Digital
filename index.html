Landing page

Uma página profissional para apresentar seu negócio, destacar sua oferta e facilitar o contato pelo WhatsApp.

Escopo deste projeto
  • Uma página responsiva para apresentar o negócio ou a oferta.
  • Seção de serviços ou benefícios e botão de contato pelo WhatsApp.
  • Informações e materiais fornecidos pelo cliente.
  • Configuração básica de títulos e metadados para SEO.
  • Uma rodada de ajustes dentro do escopo acordado.
  • Não inclui funcionalidades complexas, páginas adicionais ilimitadas, sistemas personalizados ou loja virtual.
R$ 297 / projeto↗

Site institucional

Um site profissional para apresentar sua empresa, seus serviços e suas informações comerciais.

Escopo deste projeto
  • Site institucional de escopo limitado, com até quatro páginas ou seções equivalentes conforme definição prévia.
  • Apresentação da empresa, dos serviços, das informações comerciais e das formas de contato.
  • Botão de WhatsApp, layout responsivo e configuração básica de SEO.
  • Uma rodada de ajustes dentro do escopo acordado.
  • Não é ilimitado: páginas adicionais, recursos extras e integrações especiais são orçados separadamente.
R$ 497 / projeto↗

Loja virtual

Uma loja online estruturada para apresentar seus produtos e facilitar as vendas pela internet.

O que define o orçamento

O valor varia conforme o catálogo, meios de pagamento, regras de frete, integrações, plataforma e funcionalidades. Esses itens não estão automaticamente incluídos no preço inicial.

a partir de R$ 997 / projeto↗

Quanto custa desenvolver um site?

A landing page custa R$ 297 por projeto, o site institucional custa R$ 497 e a loja virtual começa em R$ 997 por projeto. Os dois primeiros têm escopo limitado, definido previamente.

Quanto custa criar um sistema personalizado?

Um sistema web sob medida começa em R$ 1.990 por projeto. A proposta considera funcionalidades, módulos, integrações, complexidade e regras da operação.

Vocês desenvolvem sistemas para pizzarias, restaurantes e escolas?

Sim. Podemos avaliar projetos para esses e outros segmentos. Os exemplos desta página são possibilidades, não um produto único com funcionalidades pré-definidas.

Posso solicitar funcionalidades específicas?

Sim. Vamos entender sua necessidade e avaliar a viabilidade técnica para incluir as funcionalidades na proposta.

Quanto tempo demora um projeto?

O prazo é definido depois de entender o escopo, as funcionalidades e os materiais necessários para o projeto.

Os preços incluem domínio e hospedagem?

Custos de domínio, hospedagem, plataformas e serviços de terceiros são informados separadamente quando aplicáveis.

Vocês oferecem manutenção?

Sim. O Essencial acompanha sites por R$ 97/mês. O Evolução acompanha sistemas web já entregues por R$ 297/mês, com até uma hora mensal para pequenos ajustes. O desenvolvimento do sistema é orçado à parte, a partir de R$ 1.990 por projeto.

Como funciona o pagamento?

As condições de pagamento são apresentadas na proposta de cada projeto, conforme o escopo acordado.

Posso começar com uma versão simples e adicionar funcionalidades depois?

Podemos planejar uma primeira versão e avaliar evoluções futuras conforme as necessidades do negócio.
